# Generated Architecture Artifacts

[Architecture overview](../README.md) · [Documentation tree](../../TREE.md)

This directory is reserved for reproducibly generated manifests, inventories, relationship maps and rendered diagrams. Do not hand-edit generated outputs.

Every generated artifact must identify:

- the source files and generator command;
- generator version and timestamp;
- deterministic sort/key rules;
- validation command;
- owning source document or contract.

Commit small reviewable manifests that improve architecture verification. Keep build reports, caches and large runtime exports outside Git.
